# 📚 Vocab Learning — اپ یادگیری لغت انگلیسی

اپ اندروید ساده برای حفظ لغت‌های انگلیسی با **مرور فاصله‌دار**، ساخته‌شده با
[Kivy](https://kivy.org) و [KivyMD](https://kivymd.readthedocs.io).

## ✨ امکانات

- **تمرین روزانه:** هر روز تا ۱۰ لغت که موعد مرورشان رسیده نمایش داده می‌شود
  (لغت‌هایی که بیشتر اشتباه شده‌اند اول)
- **مرور فاصله‌دار:**
  - جواب درست → مرور بعدی ۳ روز دیگر؛ بعد از چند جواب درست پشت‌سرهم، لغت «یادگرفته‌شده» حساب می‌شود
  - جواب غلط → فردا دوباره می‌آید
- **تلفظ و مثال:** تلفظ صوتی، آوانگاری و جمله‌ی نمونه از
  [Free Dictionary API](https://dictionaryapi.dev) (رایگان، بدون کلید، نیاز به اینترنت)
- **افزودن لغت جدید** و **لیست همه‌ی لغت‌ها** با جستجو
- آمار لغت‌های یادگرفته‌شده و در حال یادگیری

## 📁 ساختار

| فایل | توضیح |
|---|---|
| `main.py` | رابط کاربری (صفحه‌های Home، Practice و Words List) |
| `database.py` | دیتابیس SQLite لغت‌ها و منطق مرور |
| `api_service.py` | دریافت تلفظ/مثال از Free Dictionary API و پخش صدا |
| `buildozer.spec` | تنظیمات ساخت APK |
| `.github/workflows/build.yml` | ساخت خودکار APK روی GitHub Actions |

## 🚀 اجرا روی کامپیوتر

```bash
pip install "kivy==2.3.0" "kivymd==1.2.0" certifi
python main.py
```

## 📦 ساخت APK

### خودکار (GitHub Actions)

با هر push به `main` (و هر Pull Request به `main`) APK ساخته می‌شود.
از تب **Actions** → آخرین اجرا → بخش **Artifacts** فایل APK را دانلود کنید.
از همان‌جا با **Run workflow** هم می‌شود دستی اجرایش کرد.

### دستی (لینوکس)

```bash
pip install buildozer==1.5.0 cython==0.29.33
buildozer android debug
# خروجی: bin/*.apk
```

## ⚠️ محدودیت‌های فعلی

- فونت پیش‌فرض Kivy حروف فارسی را پشتیبانی نمی‌کند، پس ترجمه‌های فارسی ممکن است
  به‌صورت مربع یا حروف جدا از هم نمایش داده شوند. راه‌حل: اضافه کردن یک فونت فارسی
  (مثلاً Vazirmatn) و کتابخانه‌های `arabic_reshaper` و `python-bidi`.
- مثال‌ها و تلفظ فقط با اینترنت در دسترس‌اند (بعد از اولین پخش، صدا کش می‌شود).
